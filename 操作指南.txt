============================================================
BidPilot 操作指南 — 完整 Demo 流程
============================================================

【前置準備】

1. 一鍵啟動前後端：
   cd /Users/aaa/Desktop/bidpilot
   ./start.sh

   啟動時會詢問：
   「是否啟用真實 DeepSeek API？」
   - 選 n：使用 mock 模式，不消耗 API
   - 選 y：輸入 DeepSeek API Key，本次啟動使用真實模型，不會保存 Key

2. 打開瀏覽器：http://localhost:5173

3. 後端地址：http://127.0.0.1:8000

4. 按 Ctrl+C 可同時停止前端與後端


【第一步：登入】

   用戶名：bid_manager
   密碼：bid123
   點擊「登入」


【第二步：建立專案】

   1. 點擊右上角「新建項目」
   2. 填寫：
      - 項目名稱：某市智慧政務服務平台建設項目
      - 項目類型：軟件類
      - 描述：某市行政審批局智慧政務服務平台建設
      - 投標截止日期：2026-10-15T17:00
   3. 點擊「創建」
   4. 專案卡片出現在工作台，點擊進入


【第三步：上傳招標文件】

   1. 在專案詳情頁「文件中心」區域，點擊「上傳文件」
   2. 選擇 sample_tender.txt（在 bidpilot/ 目錄下）
   3. 上傳後點擊「解析」按鈕
   4. 解析狀態變為「completed」


【第四步：啟動工作流】

   1. 在「工作流控制」區域，點擊「啟動工作流」
   2. 工作流開始執行，自動進入「等待確認」狀態


【第五步：確認專案事實】

   1. 點擊左側導航「事實確認」
   2. 系統從招標文件中提取了以下事實：
      - 項目名稱：某市智慧政務服務平台建設項目
      - 招標人：某市行政審批局
      - 預算：580 萬元
      - 工期：180 日曆天
      - 截止時間：2026 年 10 月 15 日
      - 部署方式：私有化部署
   3. 逐條點擊「確認」，或修改後確認
   4. 回到專案詳情頁，點擊「繼續執行」恢復工作流


【第六步：查看要求矩陣】

   1. 點擊左側導航「要求矩陣」
   2. 系統提取了約 20 條要求（資格、技術、交付、格式等）
   3. 可使用篩選器按風險等級、類型、狀態篩選
   4. 點擊「確認」處理低風險要求
   5. 回到專案詳情頁，點擊「繼續執行」


【第七步：查看技術標大綱】

   1. 點擊左側導航「技術標大綱」
   2. 系統自動生成了 18 個章節的技術標目錄
   3. 左側為章節目錄樹，右側為編輯區


【第八步：生成章節初稿】

   1. 在左側目錄中選擇「總體技術方案」章節
   2. 點擊「生成章節初稿」
   3. 系統基於招標要求和知識庫生成初稿
   4. 內容區顯示生成的正文，底部顯示引用來源
   5. 標記為「待確認」的內容需要人工審核


【第九步：執行審查】

   1. 點擊左側導航「審查中心」
   2. 點擊「開始審查」
   3. 系統輸出四類審查結果：
      - 未響應要求（覆蓋審查）
      - 事實不一致（一致性審查）
      - 未驗證引用（引用審查）
      - 過度承諾（過度承諾審查）
   4. 逐條處理：點擊「確認處理」或「忽略」


【第十步：導出】

   1. 在要求矩陣頁，點擊「導出」可匯出要求矩陣
   2. 在大綱頁，點擊「導出大綱」可匯出目錄
   3. 導出文件位於 bidpilot/uploads/{專案ID}/exports/ 目錄


【可選：添加知識庫材料】

   1. 點擊左側導航「知識庫」
   2. 點擊「添加知識」
   3. 填寫企業產品能力、案例、資質等材料
   4. 添加後可提升章節生成質量


【示範用招標文件】

   位於 bidpilot/sample_tender.txt
   內容包含：資格要求、技術要求、評分標準、交付要求
   共約 48 行，適合快速演示完整流程


============================================================
Demo 流程大約需要 5-8 分鐘
所有步驟均可通過 UI 操作，無需編寫程式碼
